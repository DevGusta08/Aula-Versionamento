O projeto consiste em uma tela simples de login feita em HTML.

Descrição:
O objetivo desta aula é aprender a manipular o histórico de commits no Git, especialmente como voltar para commits anteriores para corrigir erros. Como exemplo prático, foi criada uma página básica de login com campos para usuário e senha.

Conteúdo:
Arquivo public/index.html com a estrutura da tela de login.
Comandos Git para restaurar commits e desfazer alterações.

Como usar:
Clone o repositório:
git clone https://github.com/DevGusta08/Aula-Versionamento.git
Abra o arquivo public/index.html no seu navegador para visualizar a tela de login.
Experimente os comandos Git para restaurar commits conforme aprendido na aula.

Tecnologias usadas:
